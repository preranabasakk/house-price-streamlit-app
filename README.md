# 🏠 House Price Prediction Web App

This is a machine learning project that predicts house prices using various features like number of rooms, area, etc. The app is built using **Streamlit**.

## 🚀 Features
- Linear Regression model
- Clean and interactive UI via Streamlit
- Real-time predictions
- Visualizations using Seaborn and Matplotlib

## 📁 Files
- `house-price-predictor.ipynb`: The main Jupyter notebook
- `app.py`: The Streamlit app file
- `requirements.txt`: Python package dependencies

## 🧪 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
